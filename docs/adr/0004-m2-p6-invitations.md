# ADR 0004 — M2/P6 Invitations

Ngày: 14/11/2026 (Asia/Saigon). **ACCEPTED cho P6**. Nguồn: người dùng trả lời “xác nhận toàn bộ” sau [gói A–E P6](../../services/identity-service/report/REPORT_M2_P6_CONTRACT_01.md). Phê duyệt này riêng P6, không suy từ ADR 0003/P5. Contract được duyệt không đồng nghĩa test PASS.

Identity là provider; Gateway/Swagger/API client là consumer trực tiếp. HTTP authority [Identity OpenAPI v1.2.0](../../shared/contracts/http/identity.openapi.json), Gateway là projection bỏ internal/context headers; types sinh bằng pinned openapi-typescript. Không đổi auth/session M1 hoặc authorization P5. Không tự gán reviewer/nghiệm thu bên Event M4.

- D08: bốn POST create/accept/decline/revoke và GET self inbox theo canonical. Create 201; commands còn lại 200. Lifecycle PENDING → ACCEPTED/DECLINED/REVOKED/EXPIRED, hạn tuyệt đối 7 ngày. List all states, limit 20/max100, offset, total, sort created_at/id DESC; effective EXPIRED đọc không ghi DB. Chỉ OWNER ACTIVE đúng org tạo/revoke, chỉ recipient ACTIVE accept/decline; decline không cần inviter còn quyền. Existing membership kể cả INACTIVE trả ALREADY_MEMBER, không reactivate/ghi đè.
- D07 invitation: additive table/FK/snapshot JSONB server-side, partial unique PENDING/org/recipient. Expire dưới khóa trước tạo mới. Key → org sorted → users sorted → invitation sorted → memberships sorted; ACTIVE/quyền/recipient/scope/expiry đọc lại sau chờ khóa. Accept membership/assignments/revision/event/invitation/result commit cùng transaction. Mutation gặp expiry có thể chỉ commit EXPIRED và trả 409 ngoài transaction, không cache lỗi.
- D06 P6: operation riêng, target invitation/org trong hash normalized; key TTL24h, lock2s. Replay kiểm quyền hiện tại, không đòi PENDING/expiry/eligibility cũ. Accept replay cần đúng recipient ACTIVE và membership kết quả ACTIVE; không đòi inviter còn OWNER hoặc role snapshot còn giống membership hiện tại. Create/revoke replay cần OWNER hiện tại, decline cần recipient ACTIVE. Hết TTL xử lý fresh state, không exactly-once vô hạn; record/result/mutation nguyên tử.
- D12 P6: accept mới ghi một MembershipChanged CREATED/revision1 theo schema v1 hiện có. Create/decline/revoke/expire/replay/rollback không event/revision membership mới. Không invitation event/consumer mới.
- D09: ORG provider thật; EVENT create/accept chỉ resolver fixture inject từ test, resolve ngoài DB locks rồi transaction recheck. Normal runtime thiếu resolver fail closed; success replay không resolve lại. Event thật M4, worker RabbitMQ M3, email/frontend ngoài P6. Không có transaction phân tán hoặc cam kết lifecycle Event tương lai.

Rollback app giữ schema additive; production rollback bằng forward migration được review. Không reset/db push hoặc sửa migration cũ.
