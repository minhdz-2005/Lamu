# Hợp đồng tích hợp

`events/` chứa hợp đồng message giữa các service: envelope 8 field và danh sách field bắt buộc của 14 payload. Đó là hợp đồng ngang cấp với [docs/api/catalog.md](../../docs/api/catalog.md) và [docs/api/messaging.md](../../docs/api/messaging.md), đóng băng ở tuần 1 (§6 kiến trúc), không phải thứ bổ sung sau khi code xong broker.
